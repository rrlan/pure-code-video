⚡ Pure-Code Video v1.1.0 工具箱全能力指南

          
不仅能挑画风，还内置了 60fps 虚拟时钟渲染器、手绘水彩笔刷库、109 个 CC0 真实音效混音器与「你自己的声音」配音对齐工具

        

        
      


      

        
🚀 一行命令安装到 Codex / Claude Code（无需 GitHub 账号，安装与更新同命令）：

        
curl -fsSL https://raw.githubusercontent.com/rrlan/skill-releases/main/install.py -o /tmp/rrlan-skill-install.py && python3 /tmp/rrlan-skill-install.py pure-code-video

      


      

        

          
1. 视觉风格选片与配方检索 (530+ 款)

          
网页上直接点「复制点单口令」即可获得自包含配方；装成 Skill 后支持离线检索：

          
python3 ~/.agents/skills/pure-code-video/run.py search 水彩
python3 ~/.agents/skills/pure-code-video/run.py recipe mg-05-cel-boil

        


        

          
2. 双确定性纯代码渲染引擎 (零生图大模型)

          
① 60fps 虚拟时钟锁拍 HTML 渲染器（永不掉帧）
② @napi-rs/canvas 手绘水彩纸纹与毛笔墨线引擎（自带笔刷库 lib/）

          
node templates/high-energy-html/render.mjs
node templates/handdrawn-explainer/handdrawn-leafcutter-21s.mjs

        


        

          
3. 实录音效挂载与鼓点混音 (内置 109 个 CC0 音效)

          
内置 whoosh / click / pop / riser / impact / tick 等 13 类真实录音，自动检测音乐 <120Hz 底鼓对齐切镜，按 -16 LUFS 压限混音：

          
python3 ~/.agents/skills/pure-code-video/run.py sfx-list --category whoosh
python3 ~/.agents/skills/pure-code-video/run.py sound-pass \
  --video silent.mp4 --cues cues.json --music bgm.mp3 --out ./out

        


        

          
4. 用「你自己的声音」配音 + 逐字字幕对齐

          
支持 ① 自己录真声自动剪除“嗯/呃/结巴”+ 本机 CPU 逐字对齐；② 克隆你的音色自动读稿；③ 免配置 edge-tts 神经语音：

          
# 路线A：自己录真声 → 自动剪气口口水词 → 本机CPU逐字对齐
python3 ~/.agents/skills/pure-code-video/run.py voice-trim raw.wav script.json --out clean.wav
python3 ~/.agents/skills/pure-code-video/run.py voice-align clean.wav script.json timestamps.json --backend whisper

# 路线B：使用你的克隆音色 ID 直接按文稿合成你的声音 + 逐字时间戳
python3 ~/.agents/skills/pure-code-video/run.py voice-clone script.json full.wav timestamps.json
